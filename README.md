# grid-handnote-app README.md
> 项目名称：网格手账（单机版）
> 版本：V4 完整实现增强版
> 技术栈：Vue3 + Vite + Pinia + Vue-Router + Dexie.js + Capacitor + ECharts + Element-Plus
> 运行形态：网页原型 / Android单机APK，**纯本地单机，无后端、无登录，全部数据存储在本地设备**

## 📖项目简介
本软件是网格式功能性手账单机App，参考《希望之村》网格摆放思路，提供**8px吸附网格画布**。
支持打卡、记账、月度打卡统计、月度财务饼图、文字框、图片、贴纸自由拖拽摆放。

核心业务特点（来自需求文档V4）
1. **首页临时画布（实时模式）**：支持多块草稿画布；组件引用全局数据源，数据实时联动；
2. **手账本（快照模式）**：保存之后全部组件转为静态快照，与全局数据源解绑，留存保存瞬间画面，不受后续全局数据修改影响；
3. 首页草稿画布与手账本两套状态完全隔离，打开手账本不会污染首页草稿；
4. PC鼠标 + 移动端Touch双端支持拖拽、缩放、8px网格吸附；增加拖拽边界限制，元素不能拖出画布左上边界；
5. 图片：网页端使用base64，安卓端保存App私有目录；
6. Dexie.js IndexedDB持久化核心业务数据；
7. 增强功能：画布元素全局唯一ID防止渲染闪烁；完整JSON备份导出 & 数据导入恢复。

## 🧩数据表说明（Dexie IndexedDB）
> ⚠️注意：首页**临时草稿画布保存在localStorage，不在Dexie数据库**，不会进入JSON备份。

1. `checkItemGlobal`：全局打卡项主表，支持软删除 `isDeleted`
2. `checkRecordGlobal`：每日打卡完成记录表
3. `accountGlobal`：全局记账流水表
4. `notebookStore`：已保存手账本快照数据表，存储所有保存完成的手账画布快照。

### 重要业务约束
- 首页临时画布删除：画布内`accountItem`记账会同步删除全局流水；打卡图标仅删除画布实例，**不会删除全局打卡项**。
- 删除手账本记录：只会删除快照副本，**完全不会改动全局打卡、全局记账流水数据**。

## 🎮软件操作说明
### 首页
1. App打开直接进入首页；可以新建、切换、关闭多个草稿画布（系统强制至少保留一块画布）
2. 点击底部中间`+`加号，进入编辑模式，底部出现工具栏
3. 工具栏菜单：
   - **组件**：打卡、月度打卡统计、月度财务报表饼图、记账、今日开销
   - **文字**：选中文字框后，支持加粗、增加行距、减少行距、加大字号、减少字号
   - **图片**：上传本地图片
   - **贴纸**：添加内置贴纸
4. 编辑模式右上角：
   - 保存手账：把当前草稿转为快照，存入手账本列表
   - ✅退出编辑，锁定画布，不可拖拽编辑
5. 顶部按钮：全局重置打卡（只清空打卡记录，**不删除打卡项本身**）

### 手账本
1. 首页底部tab点击【手账本】进入手账本列表
2. 点击条目打开详情页面（独立路由，**不会修改首页草稿**）
3. 浏览模式：可删除整条手账 / 点击编辑进入编辑模式
4. 手账编辑模式：
   - **原有旧组件保持快照模式，静态展示，不响应全局数据变化**
   - 从工具栏新添加出来的组件为实时模式，读取全局打卡/记账数据
   - 保存的时候，本次新增实时组件统一转为快照固化存储

### 画布操作
1. **拖拽**：编辑模式，鼠标/手指拖拽组件整体移动，自动吸附8px网格；**禁止拖拽到画布左上角以外（x≥0,y≥0）**
2. **缩放**：文字框、图片右下角手柄拖拽缩放
3. **选中**：点击画布组件选中；点击画布空白区域取消选中；文字工具栏只对选中文字框生效
4. **删除**：每个组件左上角 × 按钮删除该画布实例
5. **画布高度**：画布右下角 +/- 调整画布纵向高度；最小高度等于一屏，不能继续缩小

> 业务特殊点：**今日开销汇总组件，不会自动刷新，需要重新点击工具栏按钮生成新组件才会更新金额**。

### 数据备份与恢复
- **导出全部备份**：首页、手账本列表页，导出Dexie四张业务数据表为JSON文件下载。
> 注意：
> 1. JSON备份**不包含首页localStorage临时草稿**，仅包含已经保存为手账本的快照、打卡、记账数据。
> 2. 图片：网页端base64图片会嵌入JSON；安卓仅保存文件路径字符串，图片真实文件不会进入备份。

- **导入恢复备份**：
  1. 合并模式（推荐）：按ID合并导入，不会删除本机已有数据；ID冲突的记录会被备份文件覆盖。
  2. 覆盖模式：**清空本机全部四张业务数据表，完全替换为备份内容，操作不可撤销！谨慎使用**。
> ⚠️导入后图片资源不会恢复，imgSrc字符串保留，但安卓设备图片无法显示。

## 📤导出JSON备份包含/不包含内容
✅ **导出（Dexie数据库）**
1. 全部打卡项配置
2. 全部每日打卡完成记录
3. 全部全局记账流水
4. 所有已经保存完成的手账本（完整画布快照：布局、位置、文字、贴纸、图片元信息）

❌ **不会导出**
1. 首页未保存的临时草稿画布（保存在localStorage）
2. 安卓端图片二进制实体文件（仅保存路径字符串）
3. 运行时临时状态：选中项、编辑模式、界面临时状态

> 导入恢复：仅恢复Dexie内业务数据；首页草稿、安卓图片无法恢复。

## ⚠️已知限制 & 待优化点
1. **边界限制**：已限制元素不能拖到画布左上(x<0/y<0)，尚未限制向右、向下超出画布边界。
2. **画布元素ID**：全部画布item生成`_itemId`唯一uuid，解决v-for渲染闪烁问题。
3. **贴纸素材**：项目内置贴纸仅为演示占位，需要自行替换真实图片素材。
4. **图片权限（Android）**：Android13+ Capacitor Filesystem使用私有目录，不需要存储权限；不要使用公共存储。
5. **ECharts内存**：饼图组件unmount已经调用dispose释放实例，避免内存泄漏。
6. 没有做首页临时草稿画布的备份导入；首页草稿存储localStorage，清除浏览器缓存草稿丢失。
7. 没有深色模式、主题自定义。
8. JSON备份只保存业务元数据，**图片二进制不参与导出**；图片保存在浏览器IndexedDB / Android App私有目录。
9. 导入恢复功能只还原业务元数据；图片二进制资源不参与备份/导入。
10. 覆盖模式导入会清空全部打卡、打卡记录、记账流水、手账本快照，操作不可撤销。
11. 清除App/浏览器全部数据，所有本地数据会全部丢失，请定期导出JSON备份。

## 🐛常见问题排查
1. **页面白屏**：检查Element-Plus是否正确导入main.js；检查路由配置。
2. **图片安卓端不显示**：确认执行过`npx cap sync android`；file-uri图片webview存在限制。
3. **保存手账本之后，组件数据还会变化**：确认保存时调用`convertCanvasItemsToSnapshot`工具，把实时item全部转为Snapshot快照类型。
4. 首页草稿丢失：首页临时画布依赖localStorage持久化，清除浏览器缓存会清空草稿；已经保存到手账本的数据存储在Dexie IndexedDB，不受localStorage清除影响。
5. 打卡、记账新增后界面不更新：确认Pinia store执行了数据库读取刷新`initLoad()`。
6. 导入备份后首页草稿不见了：属于正常现象，草稿保存在localStorage，不在备份文件内。
7. 导入备份后图片空白：安卓设备图片实体文件没有备份，仅保留路径字符串。
